# 0003. REST API для интеграций

- Status: accepted
- Date: 2025-02-20
- Authors: Architect, Integration Lead

## Context
Внешние системы: WMS, CRM, BI. Нужен единый протокол интеграции.

## Decision
Все интеграции — через HTTP-сервисы 1С.
Формат: JSON. Авторизация: OAuth 2.0.

## Alternatives
- SOAP: устаревший, тяжёлый
- Обмен через файлы: ненадёжно
- Прямое подключение к БД: небезопасно

## Consequences
Плюсы: стандартный протокол, легко тестировать.
Минусы: нужна инфраструктура балансировки.
