# 0001. Использовать EDT как основную среду разработки

- Status: accepted
- Date: 2025-01-15
- Authors: Team Lead, Architect
- Related:
- Superseded by:

## Context
Команда из 8 разработчиков, есть опыт работы в Конфигураторе.
Нужна поддержка Git, code review, unit-тестов, SonarQube.

## Decision
Переходим на 1C:EDT 2024.1 как основную среду.
Конфигуратор используется только для отладки и выгрузки .cf.

## Alternatives
- Остаться в Конфигураторе: минус — нет нормальной работы с Git
- Смешанный подход: минус — конфликты форматов

## Consequences
Плюсы: Git, code review, статический анализ, проектная структура.
Минусы: обучение команды, необходимость мощных машин.
