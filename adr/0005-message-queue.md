# 0005. Очередь сообщений для интеграций

- Status: accepted
- Date: 2025-03-15
- Authors: Integration Lead

## Context
Интеграции синхронные, есть падения при недоступности внешних систем.

## Decision
Используем RabbitMQ для асинхронных интеграций.

## Alternatives
- Kafka: избыточно для текущих объёмов
- Встроенные очереди 1С: ограниченная функциональность

## Consequences
Плюсы: устойчивость, ретраи, развязка по времени.
Минусы: новая инфраструктура, мониторинг.
